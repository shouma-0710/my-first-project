# My First Project

大学3年生がプログラミング未経験から開発を学ぶために作った学習用リポジトリです。
Pythonの基礎からGit/GitHubの使い方、Flaskを使ったWebアプリ開発、そしてデプロイまでを一通り経験しました。

## デモ

URL　https://my-first-project-gh1w.onrender.com

## できること（ToDoアプリ）

- タスク追加
- タスクの一覧表示
- タスクを完了にする

## 使用技術

- Python
- Flask
- HTML (Jinja2テンプレート)
- Git / GitHub
- Render(デプロイ)

## ローカルでの動かし方

git clone https://github.com/shouma-0710/my-first-project
cd my-first-project
python -m pip install -r requirements.txt
python app.py

ブラウザで'http://127.0.0.1:5000'にアクセスしてください。

## 学んだこと
- Gitの基本操作とブランチ・Pull Requestを使った開発フロー
- Pythonの基礎文法(関数、ループ、リスト、辞書)
- Flaskによるルーティング、テンプレート、フォーム処理
- Webアプリのデプロイ(gunicorn,Render)
